# Learning Journey

## About the App

Learning Journey is a learning activity tracking app that helps users build consistent learning habits. Users can set learning goals, track their daily progress, and maintain their learning streak.

## Features

- **Set Learning Goals:** Choose a learning topic and duration (Week, Month, or Year).
- **Daily Learning Tracking:** Mark a day as learned or undo the action using Unlearn.
- **Freeze Days:** Freeze a day when you cannot study, with a limited number of freezes.
- **Activity Calendar:** View your weekly progress and track previous activity.
- **Progress Statistics:** Track learned days, frozen days, and learning streaks.
- **Change Learning Goal:** Update your learning topic and duration.
- **Goal Results:** Get feedback when you complete or finish your learning goal.

## Technologies Used

- Swift
- SwiftUI
- Xcode
- MVVM Architecture
